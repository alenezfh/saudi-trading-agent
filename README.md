
# Saudi Trading Agent Mobile

نسخة مهيأة للجوال.

## أسرع طريقة لتشغيلها على الآيفون
1. ارفع هذا المجلد إلى GitHub.
2. اربطه بخدمة Streamlit Community Cloud.
3. اختر app.py كملف التشغيل.
4. بعد النشر افتح الرابط من Safari.
5. من Safari اختر Share > Add to Home Screen.

## تشغيل محلي
pip install -r requirements.txt
streamlit run app.py
